# Contributing

Thank you for your interest in improving the 5G Network Performance Analyzer.

## Current project scope

The current application is a static frontend simulation built with HTML, CSS, vanilla JavaScript, and Chart.js. Contributions should preserve that distinction and must not describe simulated values as live network measurements.

## Suggested workflow

1. Fork the repository.
2. Create a focused branch for your change.
3. Make a small, clearly scoped update.
4. Test the dashboard in a modern browser.
5. Check the browser console for errors.
6. Submit a pull request with a summary, testing notes, and screenshots for visual changes.

## Code guidelines

- Keep HTML semantic and accessible.
- Use responsive CSS and avoid unnecessary dependencies.
- Keep scenario data and dashboard update logic understandable.
- Use descriptive variable and function names.
- Do not add API keys, passwords, tokens, or personal data.
- Clearly label mock data and unfinished integrations.
- Update the README or relevant documentation when behavior changes.

## Reporting an issue

Include the browser and operating system, steps to reproduce, expected behavior, actual behavior, and screenshots or console errors when relevant.
